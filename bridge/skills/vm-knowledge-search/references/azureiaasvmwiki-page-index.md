> **How to use (Copilot CLI)**: feed the **"Wiki path"** column directly into `csswiki-wiki(action="get_page", path=<wiki path>, includeContent=true)` — one call returns both `page.id` and `page.content`.
>
> A legacy `Git Item Path` column (hyphen-separated, with `.md` suffix) used to be included for `csswiki-repo_file(action="get_content", path=...)` fallback scenarios. Since AzureIaaSVM is a Project Wiki and rarely needs the repo_file fallback, that column has been removed; if you ever need it, derive on the fly per [ado-wiki-url-guide.md §6](ado-wiki-url-guide.md).
>
> The "CN keywords" column on the topic tables is kept as a bilingual lookup aid — the standalone-mode workflow (SKILL.md §5) often starts from a Chinese customer query and translates to English search terms.
